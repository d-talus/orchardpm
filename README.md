# Orchard Property Management

Marketing site for Orchard Property Management, a New Jersey platform that acquires and
operates property management firms. Static HTML generated by a dependency-free Node build
and deployed on Vercel.

- Production domain: `orchardpropertymgmt.com`
- Repository: `github.com/d-talus/orchardpm`
- Parent company: Talus Holdings

## Running it locally

```bash
npm run dev
```

That builds the site into `dist/` and serves it at <http://localhost:4322> with the same
clean URLs and trailing slashes Vercel uses, so links behave locally the way they do in
production.

Other scripts:

- `npm run build` writes the whole site to `dist/`
- `npm run serve` serves an existing `dist/` without rebuilding
- `npm run check` rebuilds, then audits the output (see below)

`npm run check` fails the build on broken internal links, missing or duplicated titles and
meta descriptions, missing canonical tags, images without alternative text, headings that
skip a level, structured data that does not parse, indexable pages missing from the
sitemap, and leftover placeholder text. Run it before every deploy.

## How the site is put together

There is no framework and there are no dependencies. `src/build.mjs` reads page data,
renders every page through `src/lib/layout.mjs`, and writes static HTML.

```
public/              Copied verbatim into dist/ (CSS, JS, images, favicon)
  css/brand.css      Brand tokens: palette, type, spacing, buttons, cards, forms
  css/site.css       Layout and components built on those tokens
src/
  data/site.mjs      Identity, navigation, the four specialties, service areas, values
  data/services.mjs  Client-facing services, capabilities, New Jersey specifics
  data/blog.mjs      Blog categories
  content/blog/*.md  Blog posts, with front matter
  lib/layout.mjs     Page shell: head, meta, structured data, header, footer
  lib/modules.mjs    Reusable sections: hero, feature grid, steps, FAQ, forms, cards
  lib/icons.mjs      Inline SVG icons, including the eight brand service icons
  lib/markdown.mjs   A small Markdown subset for blog posts
  pages/*.mjs        One module per page or page family
api/lead.js          Vercel function that receives every form on the site
```

Copy lives in `src/data/` and `src/pages/`, never in the templates, so a wording change
touches one file.

### Two audiences, two sections

The site serves boards and property owners through `/services/`, and owners of management
firms through `/sell-your-business/` and `/what-we-do/`. Keep those apart. Their titles,
headings, and meta descriptions must not converge, or the two sections compete for the
same search results; `npm run check` fails the build on a duplicate title, which is the
guard rail for exactly this.

Anything in `src/data/services.mjs` under `serviceFeatures` should stay free of any one
state's rules, so a company joining Orchard elsewhere inherits the copy unchanged.
Jurisdiction-specific claims belong in `newJerseyNotes`, and every one of them is sourced.

### Adding a blog post

Drop a Markdown file into `src/content/blog/`. The front matter needs `title`, `date`, and
a `category` matching a slug in `src/data/blog.mjs`. `summary`, `image`, `imageAlt`,
`tags`, and `author` are optional. The build derives the reading time, the excerpt, the
article structured data, and the sitemap entry, and an article with three or more `##`
headings gets a contents list automatically.

### Changing the brand

`public/css/brand.css` holds every color, font, radius, and spacing value as a custom
property. The rest of the site refers to those variables, so a rebrand is a change to that
one file. The class names match the shared Talus child-theme contract, which keeps the
markup portable to Avada Builder later.

## Deploying

Vercel builds with `npm run build` and serves `dist/`. `vercel.json` sets clean URLs,
trailing slashes, long cache headers on `/assets/`, and the usual security headers.

### Form delivery

`api/lead.js` validates every submission, drops honeypot spam, and forwards the lead to
whichever destinations are configured. Set any of these in the Vercel project settings:

- `LEAD_WEBHOOK_URL` — any HTTPS endpoint that accepts a JSON POST (HubSpot workflows,
  Zapier, Make, Slack)
- `HUBSPOT_PORTAL_ID` and `HUBSPOT_FORM_GUID` — post straight into a HubSpot form
- `RESEND_API_KEY`, `LEAD_EMAIL_TO`, `LEAD_EMAIL_FROM` — send the lead as email

With none set, the function still returns success and logs the lead, so the site never
breaks in preview. Configure at least one before launch.

## Images

Web images live in `public/assets/`. Full-resolution source photography goes in
`tools/source-photos/`, which git ignores, and `tools/resize-images.ps1` regenerates the
web versions from it.

The logo lockups in `public/assets/logo/` were composed from the supplied Orchard Property
Management logo (Nov 2026) in the brand package: the illustration and the wordmark set side
by side, with the white background keyed out, plus a white version for dark backgrounds.
